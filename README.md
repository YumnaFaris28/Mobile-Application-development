PrintXpress – Custom Printing Android Application 
Mobile-Application-development
Developed a native Android application for custom printing services with user registration, product browsing, order customisation, and real-time order tracking.
Integrated Firebase Authentication and Firestore for real-time data sync, offline persistence, and cloud storage.

Designed intuitive UI following Google's Material Design guidelines and implemented session management with SharedPreferences.

Executed black-box testing (Equivalence Partitioning, Boundary Value Analysis) achieving 100% pass rate across 10 test cases
